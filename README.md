# scoop-creel

Scoop bucket for [creel](https://github.com/rsiota/creel) — a vim-driven SQL TUI.

```powershell
scoop bucket add creel https://github.com/rsiota/scoop-creel
scoop install creel
```

Manifests are synced from `packaging/scoop/` in the creel repo via
`scripts/update-packaging.sh` after each GitHub Release.
